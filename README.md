## Getting started

```sh
$ cd ~
$ git clone git@github.com:degete/zshrc.git ~/.zsh

$ ln -s .zsh/zshrc .zshrc
$ ln -s .zsh/zshenv .zshenv

# Optional (template for your local config)
$ cp .zsh/zshrc.local .zshrc.local
```
